## Prerequisites

- A web browser (Chrome, Firefox, or Edge)
- A [TypingClub](https://www.typingclub.com) account

## Run the bot

<Steps>
  <Step title="Open a lesson">
    Log in to [typingclub.com](https://www.typingclub.com), navigate to any course, and open a lesson level. The bot works on individual typing lesson pages.
  </Step>

  <Step title="Open the browser console">
    Press `F12` (or `Cmd+Option+J` on Mac) to open DevTools, then click the **Console** tab.
  </Step>

  <Step title="Paste and run the script">
    Copy the full script below, paste it into the console prompt, and press `Enter`.

    ```javascript TypingClubBot.js
    // NOTE: When delay (in ms between two strokes) is too low, the site might bug out and the result page will not be shown
    const minDelay = 60;
    const maxDelay = 60;

    const keyOverrides = {
      [String.fromCharCode(160)]: ' '    // convert hardspace to normal space
    };

    function getTargetCharacters() {
      const els = Array.from(document.querySelectorAll('.token span.token_unit'));
      const chrs = els
        .map(el => {
          // get letter to type from each letter DOM element
          if (el.firstChild?.classList?.contains('_enter')) {
            // special case: ENTER
            return '\n';
          }
          let text = el.textContent[0];
          return text;
        })
        .map(c => keyOverrides.hasOwnProperty(c) ? keyOverrides[c] : c); // convert special characters
      return chrs;
    }

    function recordKey(chr) {
      // send it straight to the internal API
      window.core.record_keydown_time(chr);
    }

    function sleep(ms) {
      return new Promise(r => setTimeout(r, ms));
    }

    async function autoPlay() {
      const chrs = getTargetCharacters();
      if (chrs.length === 0) {
        // No characters to type, move to the next level
        goToNextLevel();
        return;
      }

      for (let i = 0; i < chrs.length; ++i) {
        const c = chrs[i];
        recordKey(c);
        await sleep(Math.random() * (maxDelay - minDelay) + minDelay);
      }

      // After auto-typing ends, automatically move to the next level
      goToNextLevel();
    }

    // Function to click the button that moves to the next level
    function goToNextLevel() {
      // Wait a bit after typing before attempting to go to the next level
      setTimeout(async () => {
        const nextButton = Array.from(document.querySelectorAll('span')).find(el => el.textContent === '\u2192');
        if (nextButton) {
          nextButton.click(); // Simulate click to proceed to the next level
          console.log('Moving to next level...');

          // Wait for the next level to load before starting the typing again
          await sleep(1000); // Adjust this delay if necessary
          autoPlay(); // Call autoPlay again for the next level
        } else {
          console.log('Next level button not found.');
        }
      }, 2000); // Adjust the delay before going to the next level if needed
    }

    autoPlay();
    ```
  </Step>
</Steps>

## What to expect

Once the script runs, it reads all the target characters from the current lesson page using `.token span.token_unit` elements and types them one by one by calling `window.core.record_keydown_time()` — TypingClub's internal keystroke API.

After all characters are typed, the bot waits 2 seconds and then looks for the `→` navigation button to advance to the next level. You will see the following messages in the console as it progresses:

```
Moving to next level...
```

If the next level button is not found (for example, at the end of a course), you will see:

```
Next level button not found.
```

The bot then continues calling `autoPlay()` on each subsequent level automatically, chaining through lessons without any manual input.

<Note>
  The default delay between keystrokes is **60ms** (`minDelay = 60`, `maxDelay = 60`). Do not set this value below 60ms. If the delay is too low, TypingClub may fail to register keystrokes correctly and the results page will not be shown.
</Note>

<Tip>
  Keep your laptop plugged in while the bot runs. It can chain through many levels in a single session, and the browser staying active throughout ensures the script is not interrupted by power-saving sleep.
</Tip>

<Warning>
  The bot runs entirely in your browser session and requires the lesson page to remain open and in focus. Do not navigate away or close the tab while it is running.
</Warning>
